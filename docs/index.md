# Fried Editor

The scene editor for [Fried Engine](https://github.com/KoyFC/FriedEngine).

Fried Project Manager creates and builds projects, the engine is the runtime, and this editor assembles scenes.

- [Installing](installing.md): the releases, and building the editor from source.
- [Using](using/opening-a-project.md): opening a project, the viewport, the hierarchy and inspector, assets, play and project settings.
- [Architecture](architecture/index.md): how the editor is laid out and what was decided.
- [Development](development/index.md): the tests, releasing and the open work.
