# Shortcuts

A shortcut with a panel under Where works only while that panel has the keyboard, which a click in it gives. The others work anywhere, except while text is being typed or a dialog is open.

| Key | Does | Where |
| --- | --- | --- |
| Ctrl+N | New Scene | |
| Ctrl+S | Save | |
| Ctrl+Shift+S | Save Scene As | |
| Ctrl+Alt+S | Save All | |
| Ctrl+P | Quick Open (`>` runs a command, `@` selects a node) | |
| Ctrl+Q | Quit | |
| Ctrl+B | Build and Run | |
| Ctrl+Z | Undo | |
| Ctrl+Shift+Z, Ctrl+Y | Redo | |
| F5 | Play the project from its start scene | also while the game has the keyboard |
| F6 | Play the open scene | also while the game has the keyboard |
| F7 | Pause or resume | also while the game has the keyboard |
| F10 | Next frame, while paused | also while the game has the keyboard |
| F8 | Stop | also while the game has the keyboard |
| Ctrl+A | Create New Node under the selected node | |
| W, E, T | Move, Rotate and Scale tools | |
| F | Frame the selected node | |
| Delete | Delete the selected node | Hierarchy, Scene |
| Ctrl+D | Duplicate the selected node | Hierarchy, Scene |
| Ctrl+C, Ctrl+V | Copy and paste the selected node | Hierarchy, Scene |
| F2 | Rename the selected node | Hierarchy |
| Up, Down, Left, Right | Move through the tree, fold and unfold | Hierarchy |
| Delete | Delete the chosen file, after asking | Assets |
| Ctrl+D | Duplicate the chosen file | Assets |
| F2 | Rename the chosen file | Assets |
| G, R, S | Move, rotate or scale by following the pointer | Scene in 2D, pointer over it |
| X, Y | Hold that move or scale to one axis | during G, R, S |
| Enter or left click, Escape or right click | Keep or cancel the G, R, S change | during G, R, S |
| Ctrl while dragging | Do the opposite of the snap button | Scene in 2D |
| Right button with W, A, S, D, E, Q | Fly the camera, Shift faster | Scene in 3D |
| Escape | Give the keyboard back to the editor | Game |
| Shift+Escape | The game's own Escape | Game |
| F2, Delete | Rename or delete the chosen map, action or binding | Input Map |
| Ctrl+Plus, Ctrl+Minus | Interface scale | |

The tools use T for Scale because R and S are the Scene view's rotate and scale that follow the pointer.
